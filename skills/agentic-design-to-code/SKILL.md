# Agentic design → tested code

This is a SOREN orchestration guide. It references the curated 21st-ui-components, motionsites-design, react-three-fiber, threejs-production, gsap-motion and playwright-browser-qa skills. It does not automatically connect those tools or acquire third-party credentials.

## Workflow

1. Review the product brief, target users, content, existing design system, source screenshots and requested creative direction. Identify accessibility and performance budgets.
2. Research trusted references through permitted providers. Compare architecture/composition and record inspiration links, license constraints and distinctive visual patterns; avoid copying private paid assets.
3. Define design tokens, typography, grid, motion vocabulary, responsive behavior, states and copy. Produce a brief interaction contract for review.
4. Map proposed components to the current repository architecture. Generate or adapt code using the existing framework, not an unrelated scaffold; preserve routes, SEO, semantics, forms and analytics.
5. Where 3D is justified, coordinate React Three Fiber or Three.js rendering with GSAP motion rather than stacking competing loops.
6. Verify screenshots, responsive layouts, keyboard navigation, reduced motion, build and Playwright behavior. Compare implementation against agreed references, fix observed gaps and document remaining limitations.

## Gate

External MCP accounts require independent client consent. Permission to brainstorm or design does not approve credit spending, installing unknown packages, modifying unrelated code, deploying to production or publishing content.
