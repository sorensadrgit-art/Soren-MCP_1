# MotionSites design research

Official setup: https://motionsites.ai/mcp. The documented remote MCP endpoint is https://xgdzyqfalbibzelpdpvr.supabase.co/functions/v1/mcp and requires user sign-in/OAuth in the requesting agent. It is NOT hosted by the SOREN router.

## Workflow

1. Establish project intent, audience, layout constraints, visual language, brand palette, stack and technical performance targets.
2. Use the authenticated MotionSites prompt search/list operations to find relevant style and interaction references. Gather metadata before opening prompt text; check free vs premium access and retrieve only authorized references.
3. Extract design principles (composition, type, atmosphere, motion choreography) without claiming reference code or assets are yours. Plan an original interface and cite the source of creative direction.
4. Implement with framework-appropriate components. For 3D or intensive motion, verify GPU/CPU budgets, mobile behavior, keyboard navigation and reduced-motion fallbacks.
5. Compare browser screenshots against the agreed direction. Iterate on observed visual or usability differences, not invented provider results.

## Boundaries

MotionSites MCP is client-managed and may require browser OAuth consent. A listed configuration is not evidence of a usable authenticated session. Never bypass licensing or subscription limits, scrape paid prompts, forward secrets or auto-deploy without approval.
