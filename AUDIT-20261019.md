## Limitations and Follow-up

- Read-only public MCP; do NOT migrate private memory or privileged write tools without OAuth, per-user authorization and rate/abuse controls.
- Tool annotations and instruction text guide but cannot force host LLMs to follow precedence. Other agents' host-level policies can still supersede these hints; this MCP never acts on their behalf.
- Agent tool-name collisions are handled by the distinctive configured server alias `soren-skills`; existing names were intentionally preserved for backward compatibility.
- The router cannot enforce Git file locks or serialize writes performed independently by agents. Coordinate work using separate worktrees or an authorized task system for shared repositories.
- Stateless serverless cache is best-effort; external provider limits and availability can change.
- No new permanent desktop router/background process was installed.
